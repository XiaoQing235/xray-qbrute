## About

xray-qbrute 是帮助你计算 [Xray-core](https://github.com/XTLS/Xray-core) [Telegram](https://t.me/projectXray) 入群问题的工具。

这是 [讨论过程](https://github.com/XTLS/Xray-core/discussions/6451) 你可以在这里获得 xray-qbrute 的开发思路。

不保证 [Xray-core](https://github.com/XTLS/Xray-core) [Telegram](https://t.me/projectXray) 更换题目后的项目维护，26/7/14可用。

## Download xray-qbrute

> Go [CI Actions](https://github.com/Sn0wo2/xray-qbrute/actions/workflows/ci.yml), then find「Artifacts」, download the「xray-qbrute-builds」.
